왜 컬럼 순서가 중요할까?

- 첫 번째 컬럼을 기준으로 정렬된 상태에서만 제 역할을 할 수 있음 → 인덱스 왼쪽 접두어 규칙

복합 인덱스 대원칙

1. 인덱스는 순서대로 사용하라(왼쪽 접두어 규칙)
2. 등호(=) 조건은 앞으로, 범위조건(<, >)은 뒤로
3. 정렬(order by)도 인덱스 순서를 따르라

## 복합 인덱스 준비 과정

```jsx
show index from items;

drop index idx_items_item_name on items;
drop index idx_items_price_name on items;

create index idx_items_category_price on items(category, price)
```

## 복합 인덱스 성공 예제1: category 사용

```jsx
explain 
select * 
from items 
where category = '전자기기';
```

## 복합 인덱스 성공 예제2: category , price 함께 사용

```jsx
explain 
select * 
from items 
where category = '전자기기' 
and price = 120000;
```

## 복합 인덱스 성공 예제3: 복합 인덱스와 정렬

```jsx
-- 복합 인덱스 성공 예제3: 복합 인덱스와 정렬
explain 
select * 
from items 
where category = '전자기기' 
and price > 100000
order by price;
```

- 인덱스의 ‘전자기기’ 섹션은 이미 price 순서로 완벽하게 정렬되어 있기 때문에 데이터베이스는 별도로 데이터를 모아 다시 정렬할 필요 없이 인덱스를 읽는 즉시 order by price 조건을 만족하는 결과를 얻게 됨
