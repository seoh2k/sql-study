## 테이블 서브쿼리

```sql
-- 각 상품 카테고리별로, 가장 비싼 상품의 이름과 가격을 조회하자
select 
	p.product_id,
    p.name,
    p.price,
    p.category
from products p
join (
	select category, max(price) as max_price
	from products
	group by category) as cmp -- 인라인 뷰
on p.category = cmp.category and p.price = cmp.max_price;
```

## 서브쿼리 vs JOIN

```sql
select *
from orders o
where o.user_id in (select user_id from users where address like '서울%');

select *
from orders o
join users u on o.user_id = u.user_id
where u.address like '서울%';
```

1. join을 우선적으로 고려
2. 서브쿼리의 가독성이 훨씬 좋다면 서브쿼리를 사용
3. exists 활용
4. 성능이 의심될 때는 반드시 측정

## 문제와 풀이

```sql
-- 문제1: 가장 비싼 상품 조회하기
-- products` 테이블에서 가격이 가장 비싼 상품의 `product_id` , `name` , `price` 를 조회해라. 
-- `WHERE` 절에 스칼라 서브쿼리를 사용하여 문제를 해결해야 한다.
select product_id, name, price from products 
where price = (select max(price) from products);

-- 문제2: 동일 상품 주문정보 조회하기
-- `order_id` 가 1인 주문과 동일한 상품을 주문한 다른 모든 주문의 `order_id` , `user_id` , `order_date` 를 조회해라.
-- 스칼라 서브쿼리를 활용해야 한다.
select order_id, user_id, order_date
from orders o
where product_id = (select product_id from orders where order_id = '1')
	and order_id != '1';
    
-- 문제3: 고객별 총 주문 횟수 조회하기
-- 각 고객( `users` )별로 총 몇 번의 주문을 했는지 '총주문횟수'를 이름과 함께 조회해라. 
-- 정렬은 `user_id` 오름차순이 다.
-- 한 번도 주문하지 않은 고객도 결과에 포함되어야 한다. 
-- `SELECT` 절에 상관 서브쿼리를 사용하여 해결해야 한다.
select 
	name as 고객명,
    (select count(*) from orders o where o.user_id = u.user_id) as 총주문횟수
from users u
order by u.user_id;
```
